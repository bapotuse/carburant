# prix-carburant-mcp

Serveur MCP qui donne les prix des carburants en France : la station la moins chère
près d'un lieu, la meilleure station compte tenu de l'autonomie restante, les tendances
par département, l'empreinte carbone d'un plein.

Les outils, la configuration pour chaque client et cinq conversations d'exemple tirées
de vrais appels arrivent au Jalon 4.

Données : prix DGCCRF (Licence Ouverte 2.0), facteurs d'émission Base Carbone® de
l'ADEME (Licence Ouverte), géocodage Géoplateforme IGN.
